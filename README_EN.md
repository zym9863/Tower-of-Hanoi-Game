# Tower of Hanoi Game

## Project Introduction
This project is a Tower of Hanoi puzzle game implemented with HTML, CSS and JavaScript, featuring an elegant interface and smooth interaction, suitable for practicing algorithmic thinking and logical reasoning.

## Game Instructions
- Objective: Move all disks from the leftmost tower to the rightmost tower.
- Rules:
  1. Only one disk can be moved at a time.
  2. A disk can only be taken from the top of one tower and placed on top of another tower.
  3. At no time may a larger disk be placed on top of a smaller disk.

## Main Features
- Drag or click disks to move them.
- Real-time step counter.
- Animation highlighting the selected disk.
- Responsive design for different screen sizes.

## How to Use
1. Open `index.html` file in browser to play.
2. Click or drag disks to complete the Tower of Hanoi puzzle according to the rules.
3. Refresh the page to reset the game.

## File Structure
- `index.html`: Main page file.
- `style.css`: Stylesheet file for page styling.
- `script.js`: Core logic and interaction script.
