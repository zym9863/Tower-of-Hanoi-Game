# 汉诺塔小游戏

## 项目简介
本项目是一个基于HTML、CSS和JavaScript实现的汉诺塔益智小游戏，拥有美观的界面和流畅的交互体验，适合练习算法思维和逻辑推理。

## 玩法说明
- 游戏目标：将所有盘子从最左侧的塔移动到最右侧的塔。
- 规则：
  1. 每次只能移动一个盘子。
  2. 盘子只能从塔顶取下并放到另一根塔的顶端。
  3. 任何时刻，大盘子不能放在小盘子上面。

## 主要功能
- 拖拽或点击盘子进行移动。
- 实时步数统计。
- 动画高亮当前选中盘子。
- 响应式设计，适配不同屏幕。

## 使用方法
1. 打开`index.html`文件即可在浏览器中游玩。
2. 点击或拖动盘子，按照规则完成汉诺塔的移动。
3. 可通过刷新页面重置游戏。

## 文件结构
- `index.html`：主页面文件。
- `style.css`：样式表文件，负责页面美化。
- `script.js`：核心逻辑与交互脚本。
